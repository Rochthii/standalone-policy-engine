- `models/authority_fence.py` holds a local-authority epoch and tenant policy revision through protected commit. SQL triggers advance the epoch for user/group/membership/company/grant writes; a committed concurrent update forces REPEATABLE READ retry. The after-ALLOW manager-role schedule verifies this with fresh non-final/unconsumed state; final-first observes actual PostgreSQL blocking until successful commit.
- `internal/storage/erp_policy_fence.go` fences UpdatePolicy, PublishPolicy, DeletePolicy and ReplaceRoleInheritances. Each persists ERP `ready=false` with a publication token before the PDP mutation, then publishes its committed revision. Failure remains durably unavailable. Decision bootstrap only inserts absent rows, never clears pending state. `DecisionResult.PolicyRevision` comes from the evaluated immutable snapshot; gRPC Advice carries it and the PEP compares both approver and agent decisions against the locked ready row.
- `odoo_commit_authority_race.run_commit_authority_races`: policy/role writer-first pauses **after real final ALLOW**, commits the change, then observes final retry and denial/invalidation with no business/approval/command consumption; final-first observes the writer blocked until final commit. Policy fixtures use real revision/NOTIFY plus the publication protocol, not HTTP control-plane calls; Go integration tests separately exercise the actual production storage APIs.
- `authorization_attempt.py` adds deferred constraint validation of current grant lifecycle, grant/attempt deadline and any consumed approval deadline. Two real-clock cases pause **after actual authorized PO mutation** until grant expiry, then COMMIT raises CheckViolation and fresh sessions observe non-final PO with no consumption, for both direct and approved paths. These cases establish grant expiry at the deferred boundary; they are not separate after-check AC-expiry-only or WAL-durability-time tests.
- `test_final_policy_revision_fence_faults_preserve_approval` adds five fault-injected fence cases: missing/malformed revision, mixed approver/agent revisions, stale stored revision and pending publication. Real PDP decisions precede the injected fault; savepoint rollback leaves the approved capability and command unconsumed. This is an ERP transaction test, distinct from independent-session publication races.
